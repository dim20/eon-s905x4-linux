# v0.1-testbox

First public release. Boots Debian Linux on an EON SDSTB02 (Amlogic S905X4)
unattended from eMMC, with nothing plugged in.

## ⚠ This is a test-box release

It works on one development box. It has **not** been validated across a fleet.

Known gaps, all in the README:

1. **No network after boot.** `rescue-init.sh` does not run `dhclient` — you get
   a login prompt on HDMI and serial, no IP, no SSH.
2. **Clock reads 1970**, and there is no `/etc/resolv.conf`. `apt` cannot work
   until both are fixed; see
   [`docs/install-image-requirements.md`](https://github.com/dim20/eon-s905x4-linux/blob/main/docs/install-image-requirements.md).
3. **Installing the saved `bootcmd` needs a UART console once**, to run `setenv`
   and `saveenv`. Automating this is the next task.
4. **No automated installer is published yet.** The manual procedure is in the
   docs.

If you need this today, follow the manual procedure and expect to work from a
serial console. If you want to help finish it, the roadmap is at the bottom of
the README.

## ⚠ Read this if you have a different S905X4 box

You may not need any of this. The difficulty here is specific to this
bootloader and board family: it cannot `booti` the PE/ZBOOT-wrapped kernels
that essentially every distro ships, and the mainline device tree does not
describe the internal Ethernet PHY. If your box already boots mainline Linux
from a USB stick, stop reading — you need none of this.

## Before you write to hardware

Read [`docs/recovery.md`](https://github.com/dim20/eon-s905x4-linux/blob/main/docs/recovery.md).
Confirm you have a working UART console first. Provisioning overwrites the eMMC
user area.
