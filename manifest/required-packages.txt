# Packages the image MUST contain.
#
# One package name per line. Lines starting with '#' and blank lines are
# ignored. The name must match the "Package:" field in the image's
# /var/lib/dpkg/status exactly.
#
# Why this file exists: the requirements used to live as scattered `if`
# statements inside the build script, and they were checked against the
# INPUT tree rather than against the shipped bytes. A defect that only
# appeared during assembly would have passed. These are the requirements,
# as data, checked against the image we actually ship.
#
# See scripts/check-image.sh.

dash

# --- the login console on the television ----------------------------------
# Two things put a picture on the television, and both are on purpose:
#
#   * the DRM driver modesets when the framebuffer console binds to it;
#   * enable-hdmi.service runs /root/enable-hdmi.sh, which sets the mode
#     with modetest.
#
# The unit is belt-and-braces. Early boots left the connector disabled, and
# a mode set is runtime state, so the script makes the result independent
# of driver probe order. modetest is in libdrm-tests; the package is
# required only while that unit exists.
libdrm-tests
libdrm2
libdrm-common

# --- the optional desktop, later -----------------------------------------
# NOT a claim that a working desktop can be installed today. It cannot:
# v0.6-desktop's text was unreadable (docs/releases/errata-v0.6.md), and
# the desktop is frozen until after v0.7-tty.
#
# tasksel and tasksel-data are in the base because the next phase will
# build the optional `sc2-desktop` package set on Debian's own task
# mechanism, and because removing them from an existing image means
# editing dpkg by hand. When `sc2-desktop` lands, it should wrap or
# replace tasksel rather than depend on the user knowing which task to
# pick. Until then, running tasksel installs a desktop whose text is
# wrong. The build keeps them present; it does not advertise them.
tasksel
tasksel-data

# --- the installer needs these ------------------------------------------
# The installer copies the rootfs with rsync, preserving ownership, hard
# links, extended attributes and ACLs.
rsync
acl
libattr1
util-linux
