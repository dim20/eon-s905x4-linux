# Packages the image MUST NOT contain.
#
# One package name per line, matched exactly against the "Package:" field
# in the image's /var/lib/dpkg/status. Lines starting with '#' and blank
# lines are ignored.
#
# The rule: NO DESKTOP, NO DISPLAY MANAGER.
#
# Two reasons, and both are hard requirements rather than preferences:
#   1. The text console on the HDMI output needs the framebuffer. A
#      display manager takes it, and the box stops being a terminal on
#      the television.
#   2. A desktop is roughly 450 MB of packages in an image whose whole
#      point is to be small and to boot to a prompt in a few seconds.
#
# The desktop is not part of this image, and is frozen until after
# v0.7-tty. It will return as an optional package set; it will not become
# a second image. tasksel and tasksel-data stay in the base for that later
# work, but running tasksel today installs a desktop whose text is
# unreadable - see docs/releases/errata-v0.6.md.

# --- the X server itself -------------------------------------------------
# The image is a text console. A display manager or an X server started
# at boot takes the framebuffer away from that console, and the desktop
# path is not ready:
#
#   * v0.6-desktop's terminal text was unreadable - the X server's screen
#     pixmap was 24 bits deep in a 32-bit framebuffer (see
#     docs/releases/errata-v0.6.md), and the fix needs fb24_32;
#   * the vendor CRTC never delivers a vblank event - real, but not the
#     reason the image is text-only.
#
# The desktop returns as an optional package set, installed after the
# base is released. It is not part of this image.
xserver-xorg
xserver-xorg-core
xserver-xorg-input-all
xinit
x11-xserver-utils
