# Packages the image MUST NOT contain.
#
# One package name per line, matched exactly against the "Package:" field
# in the image's /var/lib/dpkg/status. Lines starting with '#' and blank
# lines are ignored.
#
# The rule: NO DESKTOP, NO DISPLAY MANAGER.
#
# Two reasons, and both are hard requirements rather than preferences:
#   1. The text console on the HDMI output needs the framebuffer. A
#      display manager takes it, and the box stops being a terminal on
#      the television.
#   2. A desktop is roughly 450 MB of packages in an image whose whole
#      point is to be small and to boot to a prompt in a few seconds.
#
# The user picks a desktop AFTER the install, with tasksel. That is why
# tasksel and tasksel-data are in required-packages.txt.
